Prérequis : le guide déclare `linux-utilisateurs-permissions` ; aucune ressource de ce guide (utilisateur, groupe, fichier) n'est réutilisée ici, rien à recréer. Seul `sudo apt update && sudo apt install -y lvm2` du bloc prérequis a été joué.

## Non testable ici
- step-02 : le bac à sable n'a pas d'udev (`sh: 1: udevadm: not found` affiché par parted) : `/dev/loop1p1` a été créé à la main (`mknod` depuis `/sys/block/loop1/loop1p1/dev`). Sur une vraie VM, `-P` + udev le créent seuls.
- step-04 (swap) : `/` du bac à sable est un overlayfs, `swapon /swapfile` → `Invalid argument`. Les mêmes commandes sur un fichier situé sur l'ext4 de `/mnt/data` fonctionnent (`swapon --show` → `/mnt/data/swapfile file 128M`). Sur une vraie VM ext4 la commande du guide est correcte.
- step-06 : pas de device-mapper dans le noyau du bac à sable : `lvcreate` → `/dev/mapper/control: open failed: No such device`. `lvcreate`, `mkfs`/`mount` du LV, `lvextend` et `resize2fs` non exécutés. Un redimensionnement ext4 à chaud simulé (loop agrandi + `resize2fs`) est aussi refusé ici (`Permission denied to resize filesystem`, limite noyau du bac à sable). La syntaxe des commandes est standard et la taille du VG est vérifiée.
- Persistance au reboot (`nofail`, remontage par UUID au démarrage) : pas de vrai redémarrage possible.

## Leçon pour CHECKLIST section B (si nouveau type d'erreur)
- **Pas d'écriture dans un fichier système avec une variable non vérifiée.** Un bloc qui ajoute à `/etc/fstab`, `sshd_config`, `sudoers`… une valeur calculée à l'étape précédente (`$UUID`, `$LOOP`) doit refuser d'écrire si elle est vide (`[ -n "$VAR" ] && …`) : sinon un échec en amont laisse une ligne invalide qui casse le prochain démarrage.
- **Le ménage part d'un répertoire neutre.** Si une étape fait `cd` dans un point de montage, le bloc de ménage commence par `cd ~`, sinon `umount` échoue (« target is busy ») et la suite détruit des fichiers encore montés.
- **Pas d'opération globale quand une ciblée suffit.** `losetup -D`, `docker system prune`, `iptables -F`… touchent aussi ce qui n'appartient pas au lab : cibler les ressources créées par le guide.
