## Leçon pour CHECKLIST section B (si nouveau type d'erreur)
- **Service avec démarrage lent = attente explicite.** Après un `docker run -d` d'une base (Postgres, MariaDB), toute commande `exec` collée dans le même bloc doit être précédée d'une attente (`sleep`, boucle `pg_isready`) ou d'une phrase qui annonce l'erreur transitoire. Sinon la démonstration échoue pour une mauvaise raison.
- **Sémantique de commande vérifiée sur la version installée.** Les comportements qui ont changé entre versions (`prune --volumes` : volumes anonymes seulement depuis Engine 23 ; format de `docker images` depuis 29) se vérifient sur la version courante avant publication, QCM compris.
